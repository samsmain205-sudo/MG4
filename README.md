## Devlog
FloatAnimation first begins with Start() which starts the _timer as _switchSpeed making the timer 3 seconds. While Update() changes what direction the movement goes once the _timer hits 0. So switching from _up to !_up. While StopAnimation() stops animation and is called from Player.
